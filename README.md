## 为军团而建

从一次可信的国服角色授权开始，将**军团身份、本站权限、运营数据与官方游戏操作**放在同一个工作台里。CEO 与总监建立和治理军团空间；成员只访问其所属军团、且被明确授予的内容；每一次授权、角色变更、数据同步和游戏写入动作均可追溯。

| 🛡️ 军团即租户 | 🧭 权限即准入 | 📡 运营即协同与执行 |
| :--- | :--- | :--- |
| 每个军团拥有独立数据空间，天然隔离。 | 同时校验本站角色、国服 Scope 与游戏内军团权限。 | 将资产、月矿、市场与成员工作逐步串成可执行的运营流程。 |

```mermaid
flowchart LR
    A[国服角色授权] --> B[军团空间]
    B --> C[身份与权限复核]
    C --> D[军团运营与指挥工作台]
    D --> E[数据分析 · 协同任务 · 官方游戏操作]
```

### 能力边界

系统以国服官方 API 为能力边界：已开放、可由授权角色调用的读取与写入端点都纳入建设范围；写入前必须同时满足本站权限、授权 Scope 与游戏内身份条件。当前已确认的写入方向包括游戏内邮件、联系人、舰队指挥、装配方案、日历响应与导航航点。没有官方端点的舰船操控、市场交易、合同、军团职位、建筑/月矿和工业执行，不承诺实现，也不会通过模拟客户端绕过限制。

## 安全与边界

- 不保存游戏账号密码；授权令牌、审计记录与敏感配置均受保护。
- 公开仓库不包含真实军团数据、账号凭据、令牌或生产日志。
- 本项目为非官方工具，与网易及 CCP 无隶属关系。
- 源码采用 Apache-2.0，保留上游版权与许可证；详见 [UPSTREAM.md](UPSTREAM.md)。
