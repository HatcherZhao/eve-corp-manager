# EVE Corp Manager

> 面向网易 EVE Online 国服（Serenity）军团的一体化运营管理平台。

把游戏角色授权、军团身份、权限治理与运营数据汇集到一个清晰、安全的工作台。军团 CEO 与总监可建立自己的军团空间，成员只访问其所属军团及获授权范围内的信息；每一次授权、权限变化和管理操作都可追溯。

## 已具备的能力

- **军团即租户**：由 CEO 或总监通过国服角色授权创建军团空间，数据按军团严格隔离。
- **本站账号与角色绑定**：支持创建本站账号、绑定游戏角色、找回本站密码，以及登录时的身份复核。
- **权限可信可见**：同时校验本站角色、国服授权 Scope 与游戏内军团权限；可查看完整权限树并主动刷新。
- **分级治理**：自动识别 CEO、总监和成员；CEO / 总监可配置本站业务角色并分配成员权限。
- **安全授权流程**：采用分步授权和回调地址粘贴流程，避免在系统中保存游戏账号密码；令牌、审计记录与授权状态均受保护。

## 正式开发路线图

“已具备访问资格”仅表示权限条件已满足，不代表对应业务数据模块已上线。以下路线图以可验收的业务能力为准。

### 阶段一：身份、授权与治理基础

- [x] 国服角色授权、军团租户创建与本站账号注册
- [x] CEO / 总监 / 成员身份识别和登录复核
- [x] 权限树、Scope 校验、权限刷新与重新授权
- [x] 军团成员本站角色与权限管理
- [ ] 工作台状态语义收口：将业务卡片明确标注为“开发中”或“已上线”

### 阶段二：成员与组织管理

- [ ] 同步军团成员名册、角色信息及入团 / 离团状态
- [ ] 展示管理层权限、成员归属和同步历史
- [ ] 提供成员筛选、分组、备注、权限变更审计与导出

### 阶段三：军团资源管理

- [ ] **军团资产**：资产同步、快照留存、机库与容器层级、位置 / 数量检索、筛选与导出
- [ ] **建筑设施**：建筑状态、在线服务、燃料到期、责任人和风险提示
- [ ] **月矿计划**：矿块提取、到达、自然碎裂时间线，以及矿场、责任人和参与人员的排产配置
- [ ] **采矿账本**：按成员、矿种、日期、地点汇总观察者账本，并支持明细追溯和导出
- [ ] **吉他物价与矿物估价**：读取吉他市场买卖盘与历史行情，为军团资产、月矿产出和采矿账本计算参考估值、价差和价格提醒

### 阶段四：运营协同、提醒与在线检测

- [ ] 月矿排产与协同：依据已配置的月矿周期生成内部排班、任务、责任人和时间提醒
- [ ] 在线检测：展示授权健康、数据同步状态、上游接口可用性与异常原因
- [ ] 消息提醒：支持站内通知，并预留邮件、Webhook 等通知渠道，用于燃料到期、月矿窗口、授权失效和同步失败
- [ ] **游戏内邮件通知中心**：由已授权角色发送游戏内邮件；可按消息类型、触发规则、收件对象、邮件模板和发送方式配置，并提供草稿审批、定时发送、失败重试与完整审计
- [ ] 定时同步与数据新鲜度：设置同步频率、展示数据来源时间，并支持手动补拉
- [ ] 军团运营看板：聚合资产、建筑、月矿、采矿和成员的关键指标

### 阶段五：体验与交付质量

- [ ] 前端视觉改版：统一军团运营工作台的信息层级、空状态、加载反馈和移动端适配
- [ ] 高效操作体验：全局搜索、快捷筛选、保存视图、批量操作与导出任务中心
- [ ] 完整质量保障：关键业务的自动化测试、权限回归测试、审计与安全检查
- [ ] 部署与运维：生产配置模板、备份恢复、日志监控和版本发布指引

> 平台可自动生成内部计划、排班、提醒和协同任务；但国服当前公开接口未提供月矿、建筑、资产等军团运营操作的写入能力。平台不会模拟点击或代替玩家执行游戏内指令。

## 安全与边界

系统不保存游戏账号密码，公开仓库不包含真实军团数据、账号凭据、令牌或生产日志。本项目为非官方工具，与网易及 CCP 无隶属关系；源码采用 Apache-2.0，保留上游版权与许可证，详见 [UPSTREAM.md](UPSTREAM.md)。
