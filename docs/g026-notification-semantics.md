# 通知事件范围与 MCP 统一解读

角色所属军团是通知缓存的授权来源，不能用来认定通知内建筑的资产归属。此前网页已有专门解析，但 MCP 仅暴露原始类型和正文，机器人因此将联盟主权事件混入军团建筑受袭，并遗漏阶段与节点时间。

本次后端与 MCP 复用同一解析服务。通知列表自动补充 `title`、`eventScope`、`eventScopeLabel`；正文接口补充 `interpretation`，包含中文摘要、详情、星系、建筑类型和北京时间的 `commandNodeDecloakAt`。联盟主权事件标记为 `ALLIANCE_SOVEREIGNTY`，普通建筑事件标记为 `STRUCTURE`，事件范围不表示具体所有者。原文缺少所有者时不推断所属军团或联盟。

`EntosisCaptureStarted` 解释为开始遭受侵噬，`SovStructureReinforced` 解释为进入增强模式。统一解读基于同一条已授权正文的前 20,000 字符，不受正文分页 offset 影响；`interpretationComplete` 标明是否覆盖全文。计算字段不加入 SQL 筛选、排序或聚合白名单。正文缺失或未授权时不产生业务解读，也不调用游戏接口补查。

技能同步保留线上已有的军团名称选择、成员活跃口径和封闭巡检白名单。现有军团建筑巡检继续排除联盟主权事件；用户主动查询时可明确解释联盟事件。更新两个既有任务仅修改 `note`，保留执行时间、会话、模型、目标群、燃料阈值与去重记录，不手动执行或发送消息。

验证：后端完整 fat JAR 构建成功，476 项单元测试通过；其中 86 项定向测试覆盖通知语义与 MCP 查询。技能通过 `quick_validate.py`，任务更新脚本离线校验只改说明、幂等及失败回滚。发布使用 `scripts/g026/` 中脚本，备份当前 API 和技能，保留容器资源配置，失败恢复原产物。线上验收通过真实 MCP 身份只读检查目录、窄投影、六条历史通知及正文切片行为。
