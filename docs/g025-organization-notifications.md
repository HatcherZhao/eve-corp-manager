# 建筑、军团和联盟通知展示修正

## 结果与范围

为已筛选的 25 种组织级通知补充独立中文标题和摘要，覆盖岩浆气、建筑所有权及增强时间、主权攻防与自毁、战争关系、账单、CEO、友军误伤规则、军团邀请和联盟首都。已有个人类通知继续保留原有处理；无法确认的字段省略解释，原始报文仍可展开核对。

- 6040 表示岩浆气不足一天；6041 表示岩浆气耗尽、卫星材料生产停止。
- 燃料预警数组按“数量、物品类型”解析，展示剩余燃料，不显示为待补数量。
- 绝对 ticks 时间从 UTC 转为北京时间；锚定持续时间按天、小时、分钟显示。
- 主权建筑被敌方占领后的摧毁和主动自毁分开展示；侵噬链接的 60 分钟通知间隔不作为占领倒计时。
- 邀请、接受邀请后加入军团、友军误伤倒计时与生效分别展示。
- 批量补全公开参与方名称；建筑名称只能读取当前租户、当前军团的未删除快照。
- 后端统一返回 `title`，前端保留一致的旧接口兼容标签；详情抽屉适配窄屏和长文本。
