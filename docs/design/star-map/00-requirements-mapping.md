# 星图与导航：需求与菜单映射

> 状态：设计完成，待实施（2026-09-16）

## 目标与边界

系统内提供可缩放的国服全宇宙星图，用星系和星门关系表达游戏世界，并在不泄露越权数据的前提下叠加军团运营信息。星图不是静态图片：可搜索、定位、规划航线和维护军团标注。

国服只提供宇宙坐标、星门拓扑和路线接口，不提供可嵌入的原生星图界面。系统自行渲染底图；本站标注不会写回游戏。

## 菜单与权限

| 菜单 | 使用者 | 本站权限 | 说明 |
| --- | --- | --- | --- |
| 星图与导航 → 军团星图 | 有查看权限的军团成员 | `eve:starmap:view` | 全宇宙/星域/星座/军团足迹视图、图层和星系详情 |
| 星图与导航 → 航线库 | 有查看权限的军团成员 | `eve:starmap:view` | 保存的军团航线与路线详情 |
| 维护运营标注 | CEO、总监或被授予者 | `eve:starmap:annotation:manage` | 新增、修改、归档本站星系标注 |
| 维护军团航线 | CEO、总监或被授予者 | `eve:starmap:route:manage` | 保存、改名、归档军团航线 |

## 验收映射

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| MAP-01 | 完整可用的宇宙底图 | 可浏览星域、星座、星系和星门连接；缩放后只显示当前层级必要标签，不展示内部 ID |
| MAP-02 | 军团相关信息上图 | 建筑、资产、月矿、成员最后记录位置和运营标注可独立开关；无权限图层不返回数据 |
| MAP-03 | 可读的星系详情 | 点击星系显示中文名称、星域/星座、安全等级、星门数量和可见的军团信息，附带数据时间 |
| MAP-04 | 搜索与路线 | 可按中文/英文星系名称全局搜索；两点或经由点路线使用国服路线结果并显示跳数与经过星系 |
| MAP-05 | 运营标注 | 标注只能落在星系级别，支持分类、标题、说明、颜色和到期时间；严格按军团租户隔离 |
| MAP-06 | 大数据量稳定性 | 全图不在浏览器逐项调用国服；地图资料由服务端持续同步、持久化并显示覆盖率与最近成功时间 |
| MAP-07 | 三维信息不丢失 | 全部星系保留官方 X/Y/Z 坐标；默认二维运营视图与可切换三维探索视图使用同一份数据 |
