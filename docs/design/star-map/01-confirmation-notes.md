# 星图与导航：设计口径

> 状态：基于已确认的产品边界形成的实施口径（2026-09-16）

| 主题 | 设计结论 |
| --- | --- |
| 地图范围 | 不局限于测试账号涉及的星系；完整国服宇宙都是底图数据。默认打开“军团足迹”，可切换全宇宙、星域、星座和三维探索。 |
| 信息来源 | 星系层级中文名优先沿用每日导入的 `evedata.xlsx`；坐标与星门连接以国服 Universe 接口为准；路线以国服 Route 接口为准。 |
| 自动图层 | 建筑、资产、月矿和成员追踪均从当前业务快照实时聚合，不复制成第二份地图业务数据。图层显示各自最近同步时间。 |
| 成员位置 | 只展示已有“成员追踪查看”权限者可见的最后记录位置、船型和观测时间；它不是实时定位，也不因地图而扩大可见范围。 |
| 运营标注 | 仅保存本站的星系级标注，可设“主驻地、作业区、风险、集合点、补给、其他”分类、颜色、说明和有效期。 |
| 航线 | 规划结果以官方路线返回的星系序列为准。保存的航线属于当前军团，可设置标题、说明和经由点；不把本站路线误称为游戏内航线。 |
| 数据隔离 | 宇宙拓扑是全租户共享的公开缓存；军团图层、运营标注和路线都必须带 `tenant_id`。所有接口由后端按本站权限裁剪，不能依靠前端隐藏。 |
| 性能与完整性 | 首次完整索引按照全局 3 秒最小请求间隔持续执行，允许跨重启续跑。资料未完整时仍可浏览已完成区域，并清楚显示覆盖率；不得在打开地图时向国服批量请求。 |
| 显示口径 | 用户界面只显示名称、层级和业务信息；游戏内部 ID 仅存在于服务端与基础信息页面。节点与标注聚合后显示数量，缩放到足够级别才显示名称。 |

## 不纳入的误导性能力

- 不虚构星系内精确坐标、跳桥、虫洞、异常、矿带或敌对实时态势；这些不由当前确认的国服接口提供。
- 不因用户在地图上标注，就声称游戏内出现了同名标记。
