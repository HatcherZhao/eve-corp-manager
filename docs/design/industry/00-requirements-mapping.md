# 工业制造与市场机会分析：需求与菜单映射

> 状态：已进入实施；基础计算、六页菜单与配置/校验能力已落地，快照审计、生产计划和库存模式按实施计划继续推进（2026-09-28）

> 实施计划：[09-industry-implementation-plan.md](./09-industry-implementation-plan.md)

## 目标与边界

面向国服军团管理者，基于国服静态工业数据、国服市场和星系成本指数，分析“产品 + 蓝图 + 生产配置”的生产机会，输出可执行生产计划。采购和销售固定参考吉他海军第四空间站；生产地点可选；运输成本按 0 处理。

首版是只读分析与规划能力，不执行游戏内工业、市场下单、合同或资产调拨。

## 菜单与权限

| 菜单 | 使用者 | 本站权限 | 说明 |
| --- | --- | --- | --- |
| 工业制造 → 生产机会 | 军团工业规划人员 | `eve:industry:view` | 按产品、蓝图、生产配置查询并排序机会 |
| 工业制造 → 生产配置 | 工业管理员 | `eve:industry:config:view` / `eve:industry:config:manage` | 维护技能、市场费用、生产地点、设施、Rig 和生产线配置 |

## 验收映射

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| IND-01 | 支持完整工业链模型 | 模型能表达制造、复制、研究、发明、反应、T2/T3 与旗舰相关活动；首版正式可执行范围为普通制造、反应和“蓝图已就绪”假设下的 T2 制造，发明等蓝图前置活动只展示不计成本/工时 |
| IND-02 | 国服市场口径固定 | 材料采购和成品销售只使用国服吉他 4-4 订单簿；订单按数量逐档计算 |
| IND-03 | 生产地点可比较 | 可保存多个实际或假设生产地点，包含星系、安等、建筑、服务、Rig、税率和生产线，并比较综合结果 |
| IND-04 | 成本指数正确 | 按国服 `system + activity` 读取 SCI；记录抓取时间；缺失不默认为 0 |
| IND-05 | 蓝图研究等级可配置 | 每张蓝图独立配置 ME/TE、BPO/BPC 与 runs；蓝图采购/摊销成本不计入产品成本 |
| IND-06 | 材料统一外采 | 生产材料不递归比较自制方案，一律从吉他 4-4 订单簿采购；蓝图前置活动展示但不计成本和工时 |
| IND-07 | 市场有需求才排名 | 使用吉他订单深度与伏尔戈历史成交组合计算可消化产量、销量、波动和风险 |
| IND-08 | 输出可执行计划 | 计划包含批次、材料采购、蓝图、工时、安装费、预计销量、资金占用、风险标签和来源快照 |
| IND-09 | 数据不确定性透明 | 机会分为可执行、可试算、不可执行；缺失设施资格、税率、配方验证或新鲜度不进入正式榜单 |
| IND-10 | 结果可复盘 | 保存 SDE/静态数据版本、ESI 时间、订单价格、SCI、设施和配置快照；后续刷新不覆盖旧计划 |
| IND-11 | 自动发现与人工扫描 | 支持用户手工扫描，且每天生成一次全量机会快照；默认目标周期为 1 天，安全市场占比默认 10% 并可配置 |
