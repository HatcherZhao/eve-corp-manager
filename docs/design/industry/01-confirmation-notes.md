# 工业制造与市场机会分析：确认笔记

> 状态：已确认（2026-09-27）

## 已确认口径

| 主题 | 确认结论 |
| --- | --- |
| 数据服务器 | 只支持 EVE 国服 Serenity；不混入国际服市场、SCI、税费或配方事实 |
| 分析对象 | 以“生产机会”为单位，即产品 + 蓝图 + 生产配置 |
| 生产主体 | 默认军团主体；角色技能采用固定可配置技能档案，不绑定真实角色 |
| 市场地点 | 采购与销售均固定为吉他海军第四空间站 |
| 生产地点 | 可选择多个星系和设施；市场地点与生产地点独立 |
| 运输成本 | 固定按 0 处理 |
| 材料策略 | 矿物、组件、反应材料等一律从吉他市场购买，不递归比较自制 |
| 蓝图成本 | 蓝图本身不计购买、摊销或机会成本 |
| 蓝图研究 | 每张蓝图配置 ME、TE、BPO/BPC 与 runs；研究活动本身不计成本和工时 |
| 蓝图前置活动 | 复制、发明、逆向工程在计划中展示，但首版不计成本和工时 |
| 设施配置 | 用户人工选择建筑、安等、服务、Rig、设施税和生产线，可保存复用；支持实际或假设地点 |
| 技能与费用 | 生产技能、市场交易税率和经纪费率使用可保存固定配置 |
| 成本指数 | 使用国服系统级 activity SCI；缺失时不默认为零 |
| 需求定义 | 吉他当前订单深度判断即时可成交，伏尔戈历史判断日均销量、趋势和波动；明确标注历史为星域口径 |
| 销售榜单 | 分为立即变现榜和挂单销售榜；两者都受可消化产量约束 |
| 推荐批量 | 默认按 1 天目标周期，在生产能力、订单深度和安全市场占比之间取值；允许手工覆盖 |
| 结果状态 | 可执行、可试算、不可执行；只有可执行机会生成正式计划 |
| 历史结果 | 每次正式计划保留计算快照；市场或 SCI 更新只提示，不覆盖旧计划 |
| 首版正式活动 | 普通制造、反应和“蓝图已就绪且成本为零”假设下的 T2 制造；复制、发明、逆向工程只作前置活动展示，其他活动可建模但默认不进入可执行榜单 |
| 数据源 | 国服静态工业数据为正式来源；国际服官方 SDE 只作候选回退并显式标记 |
| 校验方式 | 用国服 Golden Case 校验材料、时间、概率和设施加成 |
| 安装费版本化附加费 | 不硬编码国际服 SCC/Alpha 数值；作为设施配置项保存，必须用国服 Golden Case 校准 |

## 明确不做

- 不计算已有库存的零成本或历史成本；本模块每次均视为没有库存材料。
- 不把国际服 TQ SDE 或国际服 Jita 行情当作国服事实。
- 不自动执行游戏内制造、市场下单、合同、运输或资产移动。
- 不在缺少配方来源、设施资格、税率或关键新鲜度时伪造可执行利润。
