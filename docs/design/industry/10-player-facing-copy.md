# 工业页面玩家文案

## 约定

界面使用国服玩家熟悉的中文名称，内部字段、活动代码与计算公式保持不变。

| 原表达 | 玩家界面表达 |
| --- | --- |
| ME / TE | 材料效率 / 时间效率，分别显示并标明百分比 |
| 流程数 | 生产次数，与产出件数分开 |
| SCI | 星系成本指数，制造与反应分开 |
| 立即利润 / 挂单利润 | 直接卖出利润 / 挂卖单利润 |
| 订单深度 / 逐档采购成本 | 市场可购数量 / 采购总价 |
| EXECUTABLE / TRIAL | 可加入计划 / 仅供估算 |
| Golden Case | 游戏内对照记录 |
| 来源快照 / 固化批量 | 原始估算 / 计划产量 |

制造、反应、发明、数据校验状态、数据来源与计划步骤均使用中文展示。未知风险仍明确标为未知，不当作无风险。

## 表单与单位

- 蓝图材料效率和时间效率仍按原接口的百分数提交，例如 10 表示 10%。
- 生产线数量、技能调整后耗时、销售税与经纪人费用改用数字控件。
- 市场份额、销售税、经纪人费、设施税率及成本指数以百分数显示，提交时换回原接口的小数。例如销售税输入 3.6，提交 0.036。
- 编辑生产配置时保留其他技能、市场费率和行情有效期字段；格式损坏的原始配置不允许静默覆盖。
- 管理员所需的原始配置仍保留在高级数据维护中。配方文件导入与游戏内对照的数据格式不变。

## 验证

- `node scripts/g014/01-verify-industry-copy.mjs`：中文术语、状态与风险映射、百分比换算、额外字段保留、无效配置拒绝。
- `scripts/g014/02-mount-industry-fixture.mjs` 至 `05-verify-industry-empty-states.mjs`：本地浏览器模拟数据验收，不访问官方接口，不写线上数据。运行前按当前 Ego TaskSpace 调整任务编号。
- 浏览器验收包括有数据及空状态、生产配置保存、蓝图效率字段、成本结果与计划步骤；在 320、375、414、768、1024、1280、1440 像素宽度检查页面和表单。
- 前端 lint、typecheck、build；后端工业计算、配方导入及中文数据状态提示测试。
