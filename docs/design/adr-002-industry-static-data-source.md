# ADR-002：以 CEVE 公开工业数据作为默认计算来源

状态：已采纳。日期：2026-09-27。

国服 ESI 只提供实时市场、星系成本指数、设施/类型事实和已拥有蓝图实例的 ME/TE/runs，不提供完整的蓝图材料、产物、基础时间和概率；当前 `docs/evedata.xlsx` 也不具备这些字段。按产品决策，系统默认同步 ceve-industry.cn 的公开蓝图与反应数据，并按其已验证的公式提供计算。

国服静态导出仍可作为更高可信度的补充来源；CCP 国际服 TQ SDE 只能作为候选回退，必须标记 `source=tranquility_sde`，且不能进入“可执行”机会榜单。Golden Case 用于记录国服实测差异与回归验证，不阻断 CEVE 公开来源的计算。
