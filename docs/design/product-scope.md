# 产品范围

## 定位

一个面向国服军团管理者的经营、指挥与运营工作台。系统以有权限角色的官方授权为基础，覆盖国服 API 已开放的读取、分析、协同和写入能力；数据模型支持一个军团使用多个授权角色，并预留多军团隔离。网页中的游戏操作由服务端直接调用官方写入接口，不模拟客户端，也不绕过授权和游戏内职位要求。

## 能力边界

| 分类 | 建设原则 | 当前已确认范围 |
|---|---|---|
| 官方读取接口 | 完整接入可授权的数据能力，并标注数据来源与新鲜度 | 军团成员、资产、建筑、月矿、采矿、钱包、订单等 |
| 官方写入接口 | 只要国服提供端点、授权 Scope 与游戏身份满足，即纳入产品能力 | 游戏内邮件、角色联系人、舰队指挥、装配方案、日历响应、导航航点 |
| 国服未开放操作 | 不承诺实现，不通过模拟客户端或非官方方式绕过 | 舰船操控、市场下单/交易、合同创建或接受、军团职位、建筑/月矿、工业执行 |

写入能力必须具备明确的授权角色、目标对象、二次确认、幂等保护、接口回执和操作审计。写入失败不得假定游戏内已执行成功；新出现的国服端点须完成真实授权验证后再上线。

## 首版页面

| 页面 | 内容 | 能力边界 |
|---|---|---|
| 军团总览 | 名称、标识、CEO、联盟、成员数、税率；建筑燃料与月矿到达摘要 | 所有统计显示数据时间；缺少授权的模块不能显示成 0 |
| 资产台账 | 类型、数量、地点、机库分区、容器层级、名称补全、筛选 | 只看军团资产；未知位置保留 ID；价值估算后置 |
| 建筑管理 | 名称、类型、星系、状态、服务、fuel_expires、状态计时、拆除时间 | 可选字段缺失显示未知；当前国服无对应建筑写入端点时不伪造补燃料或服务管理能力 |
| 月矿情报 | 月球、炼化厂、开始时间、矿块到达时间、自然碎裂时间、简短备注；日历与列表 | 到达后“可引爆”，不是已经引爆；natural_decay_time 指矿块自然碎裂，不能标作矿带消失；不设置排产、负责人或协同任务 |
| 月矿账本 | 观察者、采矿角色、记录时所属军团、矿物、数量、日期；筛选汇总 | 不覆盖成员在其他地区的全部采矿；非实时；账本记录不能直接等同精确采矿事件 |
| 成员 | 名单、公开资料、入团时间、最近登录/登出、最后记录位置/船型、权限与头衔 | 追踪敏感字段单独权限控制；可选字段缺失；不推算准确在线工时 |
| 授权与同步 | 授权角色、所属军团、已授权能力、最近成功、失败原因、重授权 | 角色是数据源，站内用户权限另行配置；不让浏览器接触 EVE refresh_token |

首版站内角色建议：管理员、资产查看者、建筑/月矿管理员、人员管理员。CEO/总监用于绑定军团数据源，不应自动向每一个登录成员开放所有军团数据。

## 后续扩展

- 钱包余额、分部流水、交易分析；依据国服市场数据或人工价格表估值，保留价格时间及来源，不拿国际服 Jita 价格当作国服行情。
- 工业任务、蓝图研究等级/剩余流程、合同、订单、POS、海关设施、击毁记录：所有读取能力按契约及授权接入；发现官方写入端点时，按“授权、确认、幂等、审计、真实账号验证”流程纳入操作中心。
- 本地月矿登记：人工录入扫描组成、开采补充说明，与 ESI 数据分开标注。账本税费仅计算应缴；在国服未提供钱包写入端点前，不会自动扣款。
- 成员个人资产、技能、钱包、个人采矿等，需要本人另行授权对应角色；CEO 授权不能代替。
- 建筑燃料、月矿到达提醒先做站内提示；外部通知渠道与收件人由用户后续配置。

## 数据边界及设计要求

同一天的采矿聚合记录重复同步必须覆盖更新，不能每次累加。保留 recorded_corporation_id，不用当前所属军团覆盖历史归属。历史账本存在回溯限制，因此尽早定时同步；官方 2017 博客提到军团约 30 天、个人约 90 天，国服实际窗口仍需验证，不能承诺首次接入能回溯全部历史。

资产采用完整批次快照：所有分页成功才发布新版，部分失败保留上次完整数据。资产缺失只能表示快照差异，不能自动判定盗窃。成员离团判断也需要完整名单成功，不能在失败时把全体成员标成离团。
