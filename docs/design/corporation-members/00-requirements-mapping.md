# 军团人员模块：需求与菜单映射

> 状态：讨论稿 v0.1（2026-09-08）  
> 范围：网易 EVE Online 国服军团人员模块；不包含资产、月矿、采矿账本和游戏内写操作。

## 目标与边界

军团 CEO / 总监在本站查看本军团真实角色名册、本站业务角色和可被官方接口提供的成员追踪信息，并按本站权限将敏感数据隔离展示。模块只读取国服数据；成员备注、标签和业务分组是本站数据，不会写回游戏。

“军团成员”是游戏角色，不等同于本站用户。只有已注册并绑定角色的成员才可能关联本站用户；不得因为角色同名、昵称相同或位于同一军团就自动合并账号。

## 菜单与页面映射

| 菜单 | 页面 / 工作区 | 使用者 | 核心内容 | 状态 |
| --- | --- | --- | --- | --- |
| EVE 军团 → 军团工作台 | 能力状态卡 | 全体已授权用户 | 展示“军团人员”是否具备数据访问资格 | 已有，需调整为“功能开发中” |
| EVE 军团 → 成员管理 | 成员名册 | `eve:members:view`；追踪列另校验 | 当前成员、角色名、游戏头衔、本站角色、同步时间；获授权时展示位置、舰船、登录/登出与基地 | 本次设计 |
| 成员管理 → 成员详情 | 详情抽屉 | 同上；敏感区另校验 | 公开资料、本站关联、游戏角色、头衔、角色变更历史 | 本次设计 |
| 成员管理 → 追踪信息 | 名册列与详情区 | `eve:members:track:view` | 最近上下线、位置、舰船、基地、入团时间 | 本次设计 |
| 成员管理 → 同步记录 | 批次审计 | `eve:members:manage` | 同步结果、数据新鲜度、失败分类、来源授权 | 本次设计 |
| 成员管理 → 本站运营资料 | 标签与备注 | `eve:members:manage` | 内部分组、备注、负责人；不写回国服 | 本次设计 |

## 角色与权限映射

| 本站权限 | 授予对象 | 能力边界 |
| --- | --- | --- |
| `eve:members:view` | 经军团管理员分配的本站业务角色 | 查看基础名册、公开角色资料、本站业务角色、游戏头衔与数据更新时间 |
| `eve:members:track:view` | CEO / 总监及被显式授予该权限的任意本站角色 | 查看位置、舰船、最近登录/登出、基地、入团时间等追踪数据；非总监可被授予 |
| `eve:members:manage` | CEO / 总监或人员管理员 | 发起受限手动同步、维护本站标签/备注、查看同步审计；不能修改游戏成员、游戏角色或头衔 |
| 国服数据源资格 | 有效授权角色 | 基础名册要求 `esi-corporations.read_corporation_membership.v1` 且授权角色属于该军团；追踪要求 `esi-corporations.track_members.v1` 与 Director；其他数据按接口分别校验 |

## 功能验收映射

| 编号 | 需求 | 验收条件 | 数据来源 |
| --- | --- | --- | --- |
| MBR-01 | 查看真实成员名册 | 同步成功后显示当前成员数与角色名；跨租户查询无数据 | `/corporations/{corporation_id}/members/` + `/universe/names/` |
| MBR-02 | 识别入团/离团 | 仅在完整名册批次成功后更新在团状态；失败批次不得批量标离团 | 名册完整快照；追踪 `start_date` 仅作补充 |
| MBR-03 | 查看游戏角色与头衔 | 明确区分全局、总部、基地、其他地点角色，以及游戏头衔 | `/roles/`、`/members/titles/`、`/titles/` |
| MBR-04 | 查看成员追踪 | 拥有追踪查看权限的用户可在名册与详情直接查看；缺少时显示原因而非空白 | `/membertracking/` |
| MBR-05 | 追溯角色变更 | 显示时间、变更人、角色范围、新旧值；分页完整后发布 | `/roles/history/` |
| MBR-06 | 内部运营资料 | 标签/备注只对本军团可见，记录操作者与修改时间 | 本站数据库 |
| MBR-07 | 同步可观测性 | 展示最后成功时间、上游有效期、批次状态和脱敏失败原因 | 本站同步批次表、HTTP 缓存元数据 |

## 不在本模块范围内

- 自动踢人、授予/撤销游戏职位、修改游戏头衔、修改成员位置或舰船；国服公开接口未提供这些军团写入能力。
- 将成员追踪包装为实时在线人数、准确在线工时或持续定位。
- 通过 CEO / 总监授权读取每个成员的个人资产、技能、钱包或私人邮件；这些能力必须由成员本人另行授权。
- 将当前 `eve_corporation_member`（本站用户与其绑定角色的关系）误作全军团名册。
