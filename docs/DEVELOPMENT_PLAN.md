## 后续开发顺序

### 阶段三：资源与市场

- [x] 军团资产：当前完整快照、手动同步、位置 / 类型 / 自定义物品名称解析和层级浏览已上线。资产树按星系 → NPC 空间站 / 玩家建筑 → 仓位 → 实际物品箱（可选）→ 物品组织；舰船按“舰船分区 → 装配槽 / 改装槽 / 无人机舱 / 货仓 → 物品”分层，军团办公室按机库分层，资产安全包裹保留原存放机库，本军团玩家建筑按“建筑分区 → 燃料舱、能量槽、服务槽等具体建筑舱位 → 物品”分层。舰船由静态资料中的市场分类识别，不依赖名称或测试数据；海关办公室、玩家建筑和普通太空资产明确区分；无法解析的位置明确归入未解析分组。
- [x] EVE 静态资料：`evedata.xlsx` 的类型、市场分类、星域/星座/星系、NPC 空间站和公开建筑已持久化到数据库；启动时在资料库为空时自动导入，名称解析与资产分类优先使用数据库资料。
- [x] 基础信息菜单：新增“物品资料”和“位置资料”二级菜单；两页均支持关键词检索、筛选、分页与 CSV 导出。CEO / 总监可上传完整 `evedata.xlsx`，服务端完成六张工作表校验后在单一事务中原子替换物品与位置资料；普通成员仅能浏览和导出。已以真实账号验证菜单、列表、导出和完整文件导入，当前资料快照为 28,433 个物品类型与 15,190 个位置资料。
- [x] 国服中文名称基准：已将 `docs/evedata.xlsx` 提取为后端离线名称索引。资产与成员追踪优先使用其中的物品、星系、NPC 空间站和公开玩家建筑中文名称；未收录的新 ID 仍由国服 ESI 补齐。本军团建筑自定义名称与资产层级继续以 ESI 为准。
- [ ] 资产导出与估值：在当前层级快照稳定基础上补充下载任务和市场参考价格。
- [ ] 军团建筑：状态、服务、燃料到期、责任人与风险提醒。国服建筑读取接口已接入资产同步，仅用于名称识别；尚未持久化状态、服务和时间字段，也没有独立页面。
- [ ] 月矿：提取与到达时间线、排产、责任人和协同任务。
- [ ] 采矿账本：成员、矿种、地点、日期汇总与明细追溯。
- [ ] 吉他物价与矿物估价：买卖盘、历史价格、资产与月矿参考估值、价格提醒。
